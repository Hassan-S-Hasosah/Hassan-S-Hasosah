## Featured Project

### [Improving Phishing Email Detection Against Modern Attacks](https://github.com/Hassan-S-Hasosah/Improving-phishing-email-detection)

*Graduation Project | Team Leader & Machine Learning Developer*

Developed and evaluated a phishing email detection framework based on transformer models and hybrid feature representations.

**Key contributions**
- Led a four-member project team and developed the machine learning and deep learning pipelines.
- Implemented BERT, RoBERTa, and a Hybrid BERT architecture combining semantic embeddings with structural email features.
- Conducted model evaluation, decision-threshold analysis, and robustness testing using external and AI-generated email datasets.
- Developed the Python inference backend used by the team's Flask-based web prototype; teammates built the website interface.

**Selected evaluation results**
- **99.48% internal test accuracy** with the Hybrid BERT model.
- Evaluated **322,601 external emails**, identifying generalization challenges and elevated false-positive rates.
- Conducted additional robustness testing on **4,000 human- and AI-generated emails**.

*The repository includes source code, aggregate evaluation results, methodology documentation, and screenshots. These are academic research results; the trained weights and datasets are not included.*
